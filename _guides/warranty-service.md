## Warranty

{% capture warranty_restaurant %}
Focal heaters carry a 3-year warranty. The Overhead mount carries the same 3-year warranty.

Start with the [troubleshooting tool]({{ site.baseurl }}/fixit/) — it resolves common issues on the spot, and if it can't, it puts together the report Focal Support needs for your claim. Prefer to skip it? Email Focal Support directly with a photo of the heater's QR code or serial number and a description of the issue.

{% capture warranty_home %}
Focal Home heaters carry a 2-year warranty. Mounting kits carry the same 2-year warranty.

To make a claim, email Focal Support with the heater's serial number and a description of the issue.
