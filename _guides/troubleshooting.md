## What's wrong?

{% include fixitbanner.html %}

Prefer to read instead? Jump straight to a symptom:

- **Can't control the heater** (offline, app, or QR code) — first give the pull string a short pull. Flashing yellow lights mean Schedule Mode is active outside its scheduled hours, not a fault — see [System Setup & Control]({{ site.baseurl }}/system-setup-control/). Otherwise it's a connectivity problem: check the affected heater has power, and if all heaters are offline, check the Focal Point networking box is powered and online — see [Network Setup]({{ site.baseurl }}/network-setup/).
- **No power or lights** — re-seat the heater first (pull the string down, slide it off and back on). If other heaters on the same rail are also dark, check the rail switch and breaker, then test the outlet on a known-good circuit.
- **Heater isn't heating** — confirm it has power and isn't in Schedule Mode (see above), then try a short pull to change the heat level.
- **Heater is hard to move** — pull the string all the way down before sliding it; a partial pull won't release it.
- **Heater is physically damaged** — move it off the slot and secure any loose parts so nothing falls.
{: .symptom-list }
