## Issues

### Can't control the heater

Covers offline, app, or QR code control. First give the pull string a short pull. Flashing yellow lights mean Schedule Mode is active outside its scheduled hours, not a fault — see [System Setup & Control]({{ site.baseurl }}/system-setup-control/). Otherwise it's a connectivity problem: check the affected heater has power, and if all heaters are offline, check the Focal Point networking box is powered and online — see [Network Setup]({{ site.baseurl }}/network-setup/).

{% include video.html id="cant-control-video" src="cant-control-heater.mp4" poster="cant-control-heater-poster.jpg" qr="cant-control-heater-qr.svg" caption="Heater showing offline" %}

### No power or lights

Re-seat the heater first (pull the string down, slide it off and back on). If other heaters on the same rail are also dark, check the rail switch and breaker, then test the outlet on a known-good circuit.

{% include video.html id="no-power-video" src="no-power-lights.mp4" poster="no-power-lights-poster.jpg" qr="no-power-lights-qr.svg" caption="Checking power at the rail" %}

### Heater isn't heating

Confirm it has power and isn't in Schedule Mode (see above), then try a short pull to change the heat level.

{% include video.html id="not-heating-video" src="heater-not-heating.mp4" poster="heater-not-heating-poster.jpg" qr="heater-not-heating-qr.svg" caption="Heater online but not emitting heat" %}

### Heater is hard to move

Pull the string all the way down before sliding it; a partial pull won't release it.

### Heater is physically damaged

Move it off the slot and secure any loose parts so nothing falls.
