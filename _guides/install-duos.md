## Before you start

The rail should already be mounted, plugged in, and switched on. Duos slide onto the rail from the end opposite the switch.

{% include dodont.html do="Handle each Duo by its body, keeping the emitters and grille clear." dont="Grab or set the unit down on the grille or reflector." %}

## Open the rail end

{% include step.html number="1" title="Remove the bumper and end cap" body="Loosen the bumper set screw and slide the bumper out of the way. Remove the end cap screws and take off the end cap to open the end of the rail." diagram="duo-01-open-end.svg" %}

{% include step.html number="2" title="Remove the sliders" body="Take out the sliders so there's room to feed each Duo onto the rail." diagram="duo-02-sliders.svg" %}

## Load each Duo

{% include step.html number="3" title="Unbox and orient the Duo" body="Take the Duo out of its box. It only slides on in one orientation, so line it up before pushing it onto the rail." diagram="duo-03-orient.svg" %}

{% include step.html number="4" title="Slide in and seat it" body="Slide the Duo along the rail to its slot and push until the plug clicks into the plug point. Insert a slider behind it. Repeat for each Duo, adding spacers between units as needed." diagram="duo-04-seat.svg" %}

{% include warn.html text="Hold the end plate with one hand while driving screws. A dropped end plate has nearly struck someone on site." %}

## Close up the rail

{% include step.html number="5" title="Reinstall the end cap and bumper" body="Slide the bumper clear, refit the end cap and its screws, then slide the bumper back over and tighten its set screw. Do not overtighten the bumper set screw." diagram="duo-05-close-up.svg" %}

## Final checks

{% include checklist.html items="Every Duo clicked into a plug point | Sliders and spacers in place between units | End cap screwed on, bumper snug (not overtightened) | All heaters power on with LEDs lit | Cables routed and hidden | Each heater appears in the Focal admin app before leaving site" %}

The AC cord and plug must be routed so no part of the cable sits lower than the bottom of the rail.
