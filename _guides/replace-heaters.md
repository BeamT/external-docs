## Before you start

This covers swapping a failed or damaged heater for a replacement on a rail that is already installed and running. You remove the old heater, install the new one and then assign the new heater to the slot on the Focal Control page.

The software map has to keep matching the rail layout. Before you move anything, note which slot the failed heater sits in and the order of the heaters between it and the open end of the rail. Any heater you slide off has to go back to the same slot, or its controls will point at the wrong unit.

{% include diagram.html src="duo-00-parts.png" caption="The open end of the rail, left to right: end cap, bumper, a heater, a spacer, a second heater and the rail. Heaters and spacers come off in this order, so lay them out the same way." %}

You need:

{% include checklist.html items="The replacement heater | A phone with a camera and internet | The restaurant's Focal Control URL and password from Focal | A 2 mm hex wrench for the bumper and end cap screws" %}

{% include dodont.html do="Handle each heater by its body, keeping the emitters and grille clear." dont="Grab or set a unit down on the grille or reflector." %}

{% include warn.html text="Let the old heater cool before you touch it." %}

## Open the rail end

{% include step.html number="1" title="Find the end that opens" body="Work at the end of the rail opposite the power cord (orange). This is the end that opens." diagram="duo-01-open-end.png" %}

{% include step.html number="2" title="Loosen and slide the bumper" body="Loosen the bumper screw with a 2 mm hex wrench (1), then slide the bumper toward the center of the rail to uncover the two end cap screws (2)." diagram="duo-01-bumper-screw.png,duo-01-bumper-slid.png" %}

{% include step.html number="3" title="Remove the end cap" body="Remove the two end cap screws with the same 2 mm hex wrench (1), keeping one hand on the end cap so it doesn't fall, then take off the end cap (2)." diagram="duo-02-endcap-screws.png,duo-02-endcap-off.png" %}

## Remove the old heater

{% include step.html number="1" title="Remove the bumper and anything in the way" body="Slide the bumper off the open end of the rail. If other heaters or spacers sit between the open end and the failed heater, take them off next. To remove a heater, pull its string down firmly and then slide it off the rail. Lay everything out in the order it came off so each piece goes back to the same slot." diagram="duo-03-remove-bumper.png" %}

{% include step.html number="2" title="Take out the old heater" body="Remove the failed heater the same way: pull its string down firmly and slide it off. Set it aside to return to Focal." diagram="duo-04-remove-heater.png" %}

## Install the new heater

{% include step.html number="1" title="Unbox the new heater" body="Take the replacement out of its box. Leave the rest of the packaging on until the heater is started onto the rail." %}

{% include step.html number="2" title="Orient the heater" body="Heaters slide on from the open end of the rail, the end without the power cord. The heater only fits one way: hold it with the pull string on the trailing side, away from the rail." diagram="duo-04-orient-string.png" %}

{% include step.html number="3" title="Confirm the lug is down" body="The lug must be down for the heater to slide onto the rail. A new heater ships with a small plastic clip on top of the riser that holds the lug down. Leave the clip on, because it comes off as the heater slides onto the rail. If there's no clip and the lug is up, pull the pull string down until the lug drops." diagram="duo-05-lug-down.png" %}

{% include step.html number="4" title="Slide on and move to the old heater's slot" body="Slide the heater onto the open end of the rail (any clip comes off as it goes), then remove the rest of the packaging. Pull the string down firmly to release the heater, slide it to the exact slot the old one came out of, and let go to lock it in place." diagram="duo-06-inserted.png" %}

{% include step.html number="5" title="Put the other heaters back the way they were" body="Slide the heaters you removed back into their original slots, in the same order, with one spacer between each pair. Since they return to the same slots, their assignments stay correct. Only the new heater needs assigning." %}

## Close up the rail

{% include step.html number="1" title="Reinstall the bumper and end cap" body="Slide the bumper back onto the rail and push it clear of the end, then refit the end cap and its two screws (1). Slide the bumper back against the end cap and tighten its screw (2). Do not overtighten the bumper screw." diagram="duo-02-endcap-screws.png+duo-01-bumper-screw.png" %}

## Reassign the slot

The old heater's slot in Focal Control still points at the unit you just removed, so you need to point it at the new heater. Leave every other slot alone. Those heaters went back where they were, so their assignments are still right.

{% include warn.html text="The software layout must match the rail. If the slot points at the wrong heater, staff will turn on the wrong unit and think the system is broken." %}

{% include step.html number="1" title="Open the Focal Control page" body="Sign in with the URL and password from Focal. On the zone map, find the slot the old heater came out of." diagram="reg-01-map.png" %}

{% include step.html number="2" title="Open Assign Devices" body="Tap the menu icon in the top left and choose Assign Devices." diagram="reg-02-nav.png" %}

{% include step.html number="3" title="Select the old heater's slot" body="Tap the slot the old heater came out of. The panel below shows the heater still assigned to it, which is the old unit's serial." diagram="reg-06-heater-selected.png" %}

{% include step.html number="4" title="Scan the new heater's QR code" body="Tap the camera icon and allow camera access if your phone asks. Point the camera at the QR code on the new heater, the round tag labeled SCAN TO HEAT. Once it reads, tap Save Heater Assignment to point the slot at the new heater." diagram="reg-05-scan.png" %}

## Confirm the new heater

{% include step.html number="1" title="Go to Heater Control" body="Open the menu in the top left and choose Heater Control." %}

{% include step.html number="2" title="Tap the slot and set a heat level" body="Tap the slot you just reassigned, then tap 1, 2, or 3. Look up at the new heater. Its LEDs should change to match the level you picked and it should start putting out heat. If a different heater responds, go back to Assign Devices and fix the assignment." diagram="reg-07-heater-hot.png" %}

{% include step.html number="3" title="Turn it back off" body="Tap 'Turn off all heaters' so nothing is left running before you go." %}

## Final checks

{% include checklist.html items="The new heater sits in the same slot the old one came out of | Every other heater is back in its original slot with a spacer between each pair | The reassigned slot commands the new heater and no other | Bumper back on the rail, end cap screwed on, and bumper screw tightened" %}

If the new heater won't come online or the wrong unit responds, see [Troubleshooting]({{ site.baseurl }}/troubleshooting/).
